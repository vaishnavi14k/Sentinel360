# Sentinel360 Data

This folder contains synthetic financial data used by Sentinel360.

## Folder Structure

### raw

Contains generated source data.

### processed

Contains cleaned and transformed data.

### quality

Contains data quality check results.

### reconciliation

Contains transaction reconciliation results.

## Data Disclaimer

All data used in this project is synthetic and created for
educational and portfolio purposes.

No real customer, banking, transaction, or financial information
is used.
