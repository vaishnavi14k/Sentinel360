# Sentinel360

## Financial Compliance Intelligence & Investigation Platform

Sentinel360 is an educational end-to-end analytics platform built using
synthetic financial data.

The platform focuses on:

- Data quality monitoring
- Data validation
- Transaction reconciliation
- Anomaly detection
- Risk analysis
- Compliance investigation workflows
- Reporting automation
- Case management
- AI-assisted investigation summaries

## Technology Stack

- Python
- PostgreSQL
- SQL
- Power Query
- Power BI
- DAX
- SharePoint
- Power Automate
- Power Apps
- FastAPI
- Generative AI
- Git/GitHub

## Disclaimer

This project uses synthetic data and illustrative risk rules for
educational and portfolio purposes. It does not represent real
financial institution controls, regulatory rules, or production AML
systems.
